# 🎂 Sweet Wishes — Interactive Greeting Card

เว็บการ์ดอวยพรที่สร้างด้วย HTML + CSS + JavaScript

## ฟีเจอร์
- สร้างการ์ดพร้อมชื่อ หัวข้อ คำอวยพร และชื่อผู้ส่ง
- 4 ธีม
- เพิ่มรูปภาพหลายรูป
- เพิ่มเพลงจากเครื่อง
- เค้ก + ปุ่มเป่าเทียน + confetti
- Responsive สำหรับมือถือ
- สร้าง QR Code
- สร้างลิงก์การ์ดด้วย URL hash
- เปิดการ์ดจาก QR ได้โดยไม่ต้องใช้ backend สำหรับข้อมูลที่ฝังอยู่ใน URL

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิด `index.html` ใน browser
3. กด "สร้างการ์ด"
4. กรอกข้อมูล
5. เพิ่มรูป/เพลงได้
6. กด "สร้างการ์ด"
7. กด QR Code

## สำคัญเรื่อง QR และการแชร์จริง
ถ้าต้องการให้มือถือเครื่องอื่นสแกนได้:
- ต้องนำโฟลเดอร์นี้ไป deploy บนเว็บ เช่น GitHub Pages, Netlify หรือ Vercel
- QR จะชี้ไปยัง URL ของหน้าเว็บนั้น

ข้อมูลข้อความ/ธีมถูกฝังใน URL hash
รูปภาพจะถูกฝังด้วยเมื่อขนาด URL ยังไม่ใหญ่เกินไป
เพลงไม่ได้ถูกฝังใน QR เพราะไฟล์เพลงทำให้ URL ใหญ่มาก

ถ้าต้องการระบบ production ที่เก็บรูป/เพลงบนอินเทอร์เน็ตจริง ๆ ควรเพิ่ม backend/database/storage เช่น Supabase หรือ Firebase ในขั้นต่อไป


## 🔧 QR Code เวอร์ชันแก้ไข
เวอร์ชันนี้ไม่พึ่ง `qrcode.min.js` จาก CDN แล้ว แต่สร้าง QR เป็นรูปผ่านบริการ QR ออนไลน์
ดังนั้นต้องมีอินเทอร์เน็ตตอนกดสร้าง QR

> การเปิด `index.html` แบบ `file://` จะยังไม่ทำให้ URL ใช้ได้จากมือถือเครื่องอื่น
> สำหรับการใช้งานจริง ให้ deploy เว็บขึ้น GitHub Pages / Netlify / Vercel ก่อน
